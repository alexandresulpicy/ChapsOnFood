# Chaps & Food

A food ordering concept for the Lubbock Christian University campus.

## The problem
Students had no way to order food ahead. Ordering meant walking over
and waiting in line between classes.

## What I built
A functional ordering site: menu browsing, item selection, cart, and
order submission. I defined the concept, the feature set, and the
ordering flow.

## Stack
HTML, CSS, JavaScript. Built with AI assistance.
Course project — Web Programming, Lubbock Christian University.
